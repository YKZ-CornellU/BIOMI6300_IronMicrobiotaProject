Interpretation 1:

In this project dataset, there are no chlorophyll and mitochondria ASV being detected. This is not superising, as they used a different primer set for V5-V6 which is less commonly applied for bacterial 16s sequencing. I think more generally/prevalently used primers might give higher detection rate of those contaminants, and the results seeing here is suggesting this dataset has good primer specificity with no host/dietary carryover.

Interpretation 2 and 3:

This project dataset has no negative control and no mock community. It’s harder to assess the accuracy of the sequencing, this is certainly a limitation in their microbial sequencing study design.
